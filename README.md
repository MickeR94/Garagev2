# Garagev2

This project builds upon the original Garage-project. The difference is that this is an exercise in using List, whereas the original was using arrays.


## Functionality
The functionality is the same as the previous version. The user can add/remove a vehicle, they can search for a vehicle based on either registration number or features such as number of tyres or color.


## Future Work
More error-handling needs to be implemented. There is no way to check if the registration number is either a valid one for example.
